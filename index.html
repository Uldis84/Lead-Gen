Einrichtung
Setup Guide
1
YouTube API Key holen (kostenlos)
1. Gehe zu console.cloud.google.com
2. Neues Projekt erstellen
3. "APIs & Services" → "Bibliothek" → "YouTube Data API v3" → Aktivieren
4. "Anmeldedaten erstellen" → "API-Schlüssel" → Key kopieren
5. Key in ⚙ Settings einfügen
Kostenlos: 10.000 Requests/Tag
2
Anthropic API Key (für AI Assessment)
1. Gehe zu console.anthropic.com
2. "API Keys" → "Create Key" → Key kopieren
3. Key in ⚙ Settings einfügen
~$0.003 pro Assessment — 1000 Channels ≈ $3
3
Auf GitHub Pages deployen
1. Diese Datei als index.html speichern
2. Neues GitHub Repo erstellen → index.html hochladen
3. Settings → Pages → Source: main → Save
4. URL: dein-name.github.io/lead-tracker
Leads werden lokal in deinem Browser gespeichert
4
Workflow
1. 🔍 YouTube Search → Keyword: "food london vlog", "travel creator"
2. 20–50 Channels automatisch mit Subs + Kontakt
3. ⚡ AI Assess All → High / Moderate / Low Fit
4. High Fits importieren → DMs schreiben → Status tracken
